NEO CAMPUS MARKETPLACE - SETUP

This project copy adds a Campus Marketplace to your existing NEO PHP/MySQL app.

IMPORTANT:
1. Keep your original folder/backup. Do not delete it.
2. Copy the updated project files into your project folder, allowing the new files and updated files to be added/replaced. Do not copy the .git folder from this archive (there is no .git folder included).
3. In MySQL Workbench, open sql/marketplace_migration.sql and run it against your existing social_app database. This migration only adds the marketplace_products table; it does NOT drop your database or erase your existing posts/users.
4. Make sure config/database.php still matches your local MySQL username/password/database.
5. Run the site the same way you normally do, log in, then click Marketplace in the Quick Access panel or open public/index.php?page=marketplace.

Marketplace features included:
- Browse listings and search by title, description, or category
- Create listings with product photos (JPG/PNG/WEBP up to 5 MB)
- Edit/delete your own listings
- Category, condition, price, seller, and description
- Uses the existing users table and existing PDO database connection

If your local project uses a different database name than social_app, change config/database.php as needed and run the migration while the correct database is selected in MySQL Workbench.
